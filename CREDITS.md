# Credits

Beamline is original work by Arunkumar K S for the Meta VR Start Developer Competition 2026.

- Puzzle geometry, board, beam, mirrors, prisms, blockers, targets, and buttons are procedural. No downloaded models or textures are shipped.
- Twist ticks and the win chord are generated in the browser with WebAudio oscillators. No audio files are shipped.
- [Immersive Web SDK](https://github.com/facebook/immersive-web-sdk) (`@iwsdk/*`) is MIT licensed, © Meta Platforms, Inc. and affiliates. The project was scaffolded with `npm create @iwsdk@latest`.
- Three.js is consumed as `super-three` through IWSDK, MIT licensed.
- The browser Enter XR control and the desktop headset emulator come from IWER, which IWSDK injects in development.

No third-party music, sound effects, or network services are used at runtime.
